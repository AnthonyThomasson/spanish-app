# AGENTS.md — spanish-app

A Spanish learning app built with Vite and TypeScript. Run it with `npm run dev`; use `npm run dev:phone` for HTTPS on a phone. Generate the required local vocabulary with `uv run scripts/extract_vocab.py "/path/to/book.pdf"` (macOS/Swift/uv required). Never commit `data/vocab.json` or `extraction/`; they contain copyrighted book material.

**Issue tracker:** GitHub Issues on `AnthonyThomasson/spanish-app`.

This repository is public. Never commit secrets, API keys, or `.env` files.
